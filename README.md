
# BoutiqueCOGI-4

E-commerce et market place COGI

Mon projet est en Nextjs 16.4.6 avec:

- Tailwindcss v4
- Prisma orm 8.0.0.rc-23
- PostgreSQL Supabase	(Base de données)
- Better-Auth	(Authentification)
- Supabase Storage	(Stockage des médias)
- Redis	(Cache, limitation de débit et coordination)
- Zod	(Validation)
- Zustand	(État client)
- CinetPay	(Paiements)
